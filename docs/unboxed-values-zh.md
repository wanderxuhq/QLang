# 裸值表示:表示属于"值",装箱属于"使用点"

（英文原文见 `docs/compiler-next-steps.md` 的 "Unboxed values" 一节,本文件是该节的中文版。）

## 不变量(已定)

**每个节点只有一个"自然表示"** —— 由编译期(`aot/types.ql`)算出来、标在节点上。**任何消费者都不得改写它。**

- 某个使用点需要装箱值,就在**那一个使用点**做一次强制转换(`bitcast` + pack,两条指令);
- 某个使用点能直接吃裸值,就**原样用**,零成本;
- **绝不因为"有一个消费者要装箱"就把节点降级成装箱** —— 那会让这个值**在所有使用点都装箱**。

即:**装箱按"使用点"计,不按"值"计。**

## 三种表示

| 表示 | 寄存器 |
|---|---|
| `"Number"` | 裸 `double` |
| `"Boolean"` | 裸 `i1` |
| `""` | 装箱 `%ql_value` |

`emitValue(node) -> { reg, raw }` 返回**自然表示**;它**不接受 `want` 参数**,不看消费者。

## 表示规则(自底向上,在分析的第二遍里算)

前置事实:`inferTypes` 本来就**跑两遍** `inferStmts`(`types.ql:355` 与 `360`)—— 第一遍收集全部写入,第二遍标注。所以判 `runtimeTypeFree` 时已看得到所有写入(含后面才出现的闭包写入),**解箱前提是可靠的**。

| 节点 | 何时为裸 |
|---|---|
| `Number` 字面量 | 恒为 `"Number"`(零指令:`f64lit`) |
| `Identifier` | 取**被解析到的那个绑定**的表示 —— 需要一条与 `typeScopes` 平行的"表示作用域栈",遮蔽与闭包捕获才会自然正确 |
| `UnaryOp` `!` | 操作数为 `"Boolean"` 时为 `"Boolean"` |
| 算术 `+ - * & \| ^` | 两侧都是 `"Number"` 时为 `"Number"` |
| 比较 `== != < <= > >=` | 两侧都是 `"Number"` 时为 `"Boolean"` |
| 其余 | `""`(装箱) |

最后一行的 `""` 就是**格上的 join**:算**一次**、存在节点上 —— 而不是像试算版那样每次发射都重算并向上传染。

## 使用点

**能吃裸值(零成本)**:裸算术与裸比较、`if`/`while` 条件、写入解箱绑定的槽、以及**被调者表示签名静态已知**时的实参与返回值。

**只能吃装箱值(在此处强制转换,且仅在目标静态未知时)**:对象与数组的写入、被调者未知时的实参与返回、字符串运算。

「跨边界」不是特例:调用、返回、写入**都只是使用点** —— 目标静态已知且能吃裸值就**直接裸传**(即"能裸就裸"),未知才在那一处装箱。

## 为什么否掉了试算方案

本分支上试过一版"生成端先试算、失败再回退"的实现(`emitMayBeRaw` + emit-then-fall-back),量测结果:

- 程序里共 **897 个 `fcmp`**,走裸路的只有 **2 个**(≈99.8% 的试算注定失败);
- 每次失败都会把**操作数重新发射一遍**(第一份留在输出里成为死指令),所以**行数只涨不跌**;
- 根因是**判据错位**:白名单看的是**节点形状**("标识符原则上可以裸"),而真正的条件是**语义**("这个绑定到底解箱没有")。

换成"表示算一次、标在节点上"之后:**一个节点只有一条发射路径** → 「试算失败」与「重复发射」这两个状态**从结构上消失**;行数也变回**单调**(这正是验收指标成立的前提)。

## 槽位政策(属于"表示域",与上面的不变量无关)

可解箱 = **内建标量注解** + `runtimeTypeFree` 成立 + **函数局部**。

- 模块根绑定**永不**解箱:扩展桥会把帧 `memcpy` 给解释器,那是"使用点未知"的极端情形;
- 槽位布局**不变**(64 字节,ABI `binding=64`),只是值字段里放的是裸值,编译器单方面知道。

## 开工顺序

1. 分析层算 `staticRep` + 表示作用域栈 —— **不动生成端**,先只统计"每种表示各多少个节点"(零行为变化,可独立验证);
2. 生成端照 `staticRep` 发裸路:读取、算术、比较、条件;
3. 解箱槽与注解参数的**裸写入**;
4. 只在**确实未知**的使用点装箱。

## 验收

- **裸比较命中数从 2 涨到数百**;
- IR 行数跌破 **215919**(t20 基线);
- 探针输出不变(20 / 20 / 21 / 4);
- 解释器 **53/53**、自举门禁 **47/47**。

**先报命中数,再报行数** —— 否则"改了却没生效"会被读成"优化没收益"(本轮 897 比 2 就是这么被误读的)。
